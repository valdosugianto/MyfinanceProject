# Spesifikasi Tema Aplikasi

## Alternatif 1 — MyFinance (direkomendasikan)
### Deskripsi masalah
Mahasiswa sering kesulitan mengetahui ke mana uang bulanan digunakan karena transaksi kecil seperti makan, transportasi, pulsa, dan hiburan tidak tercatat secara konsisten.

### Target pengguna
Mahasiswa aktif yang menggunakan smartphone/laptop dan memiliki uang bulanan terbatas.

### Manfaat
Membantu pengguna mengetahui saldo, memantau pengeluaran, dan membangun kebiasaan mencatat keuangan.

### Fitur inti
1. Dashboard saldo
2. Tambah pemasukan/pengeluaran
3. Riwayat transaksi
4. Hapus transaksi
5. Target tabungan
6. Penyimpanan data lokal

### Tidak dikerjakan
Bank API, transfer uang, payment gateway, investasi, multi-user, sinkronisasi cloud.

### Kriteria keberhasilan
Pengguna dapat menambah transaksi, saldo otomatis berubah, transaksi dapat dihapus, data tetap ada setelah refresh, dan seluruh UI dapat dijalankan tanpa error.

## Alternatif 2 — FoodBudget
Aplikasi pencatat pengeluaran makanan mahasiswa.
Fokus: batas budget makan harian, pencatatan pembelian makanan, kategori makanan, dan ringkasan pengeluaran.
Tidak dikerjakan: pemesanan makanan, pembayaran, delivery tracking.

## Alternatif 3 — CampusTask
Aplikasi manajemen tugas kuliah.
Fokus: daftar tugas, deadline, prioritas, status pengerjaan, dan dashboard progres.
Tidak dikerjakan: integrasi LMS kampus, kalender eksternal, kolaborasi real-time.

## Pemilihan
MyFinance dipilih karena masalahnya jelas, fitur dapat dibatasi, alur data sederhana, dan realistis diselesaikan serta diuji dalam 12 pertemuan.
