# MyFinance

Aplikasi web pencatatan keuangan sederhana untuk mahasiswa.

## Teknologi
- React
- Vite
- Lucide React
- LocalStorage

## Fitur
- Dashboard saldo
- Total pemasukan dan pengeluaran
- Tambah transaksi
- Hapus transaksi
- Riwayat transaksi
- Target tabungan
- Data tersimpan di browser melalui LocalStorage

## Cara menjalankan
Pastikan Node.js sudah terpasang.

```bash
npm install
npm run dev
```

Kemudian buka alamat yang ditampilkan Vite, biasanya:
http://localhost:5173

## Struktur
src/main.jsx  -> komponen dan logika aplikasi
src/styles.css -> tampilan/UI
index.html -> entry HTML
package.json -> dependency dan script
